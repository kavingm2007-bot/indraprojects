# INDRAPROJECTS website

Plain HTML / CSS / JavaScript. No build step, no install.

- **Run locally:** double-click `index.html`.
- **Deploy on Vercel:** drag this folder into vercel.com/new (or push to GitHub and import it). Framework preset: **Other**. Leave Build Command and Output Directory empty.

## Edit later
- Contact details and social links: top of `js/main.js` (`SITE`).
- Services and projects: `js/data.js`.
